## 📋 Problem Statement

Given two strings `s` and `p`, return an array of **all the start indices** of `p`'s anagrams in `s`.

You may return the answer in **any order**.

An **Anagram** is a word or phrase formed by rearranging the letters of a different word or phrase, using all the original letters exactly once.

---

## 🧪 Examples

### Example 1

```text
Input:  s = "cbaebabacd", p = "abc"
Output: [0,6]

Explanation:
The substring starting at index 0 is "cba", which is an anagram of "abc".
The substring starting at index 6 is "bac", which is also an anagram of "abc".
```

### Example 2

```text
Input:  s = "abab", p = "ab"
Output: [0,1,2]

Explanation:
The substrings "ab", "ba", and "ab" are all anagrams of "ab".
```

---

## ⚙️ Constraints

| Constraint | Value |
|---|---|
| String Length | `1 <= s.length, p.length <= 3 × 10⁴` |
| Characters | `s` and `p` consist of lowercase English letters |
