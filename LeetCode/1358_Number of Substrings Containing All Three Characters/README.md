## 📋 Problem Statement

Given a string `s` consisting **only** of the characters `'a'`, `'b'`, and `'c'`.

Return the **number of substrings** containing **at least one occurrence** of **all three characters** `'a'`, `'b'`, and `'c'`.

---

## 🧪 Examples

### Example 1

```text
Input:  s = "abcabc"
Output: 10

Explanation:
The substrings containing at least one 'a', one 'b', and one 'c' are:
"abc", "abca", "abcab", "abcabc",
"bca", "bcab", "bcabc",
"cab", "cabc",
"abc".
```

### Example 2

```text
Input:  s = "aaacb"
Output: 3

Explanation:
The valid substrings are:
"aaacb", "aacb", "acb".
```

### Example 3

```text
Input:  s = "abc"
Output: 1
```

---

## ⚙️ Constraints

| Constraint | Value |
|---|---|
| String Length | `3 <= s.length <= 5 × 10⁴` |
| Characters | `s` consists only of `'a'`, `'b'`, and `'c'` |
