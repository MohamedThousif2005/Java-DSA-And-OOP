## 📋 Problem Statement

You are given a string `s` consisting of lowercase English letters.

Return an integer denoting the **maximum number of substrings** you can split `s` into such that **each substring starts with a distinct character** (i.e., no two substrings start with the same character). :contentReference[oaicite:0]{index=0}

---

## 🧪 Examples

### Example 1

```text
Input:  s = "abab"
Output: 2

Explanation:
Split "abab" into "a" and "bab".
Each substring starts with a distinct character ('a' and 'b').
```

### Example 2

```text
Input:  s = "abcd"
Output: 4

Explanation:
Split "abcd" into "a", "b", "c", and "d".
Each substring starts with a distinct character.
```

### Example 3

```text
Input:  s = "aaaa"
Output: 1

Explanation:
All characters are 'a', so only one substring can start with 'a'.
```

## ⚙️ Constraints

| Constraint | Value |
|---|---|
| String Length | `1 <= s.length <= 10⁵` |
| Characters | `s` consists of lowercase English letters |
