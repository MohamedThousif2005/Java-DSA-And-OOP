## 📋 Problem Statement

The **Hamming distance** between two integers is the number of positions at which the corresponding bits are different.

Given two integers `x` and `y`, return the **Hamming distance** between them.

---

## 🧪 Examples

### Example 1

```text
Input:  x = 1, y = 4
Output: 2

Explanation:
1  = (0 0 0 1)
4  = (0 1 0 0)
          ↑   ↑
The differing bits are marked above, so the Hamming distance is 2.
```

### Example 2

```text
Input:  x = 3, y = 1
Output: 1

Explanation:
3 = (0 0 1 1)
1 = (0 0 0 1)
        ↑
Only one bit differs.
```
